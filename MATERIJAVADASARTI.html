Teori Dasar

01. Java itu apa sih?

Java adalah bahasa pemrograman yang digunakan untuk membuat aplikasi, mulai dari desktop, web, hingga mobile. Java bersifat object-oriented (OOP), artinya program dibuat menggunakan konsep objek agar lebih terstruktur dan mudah dikembangkan.

Keunggulan Java:

- Bisa dijalankan di berbagai sistem operasi

- Banyak digunakan di dunia industri

- komunitas besar
