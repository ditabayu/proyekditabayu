Teori Dasar

01. Apa itu Mobile Programing?

Mobile programming adalah proses pembuatan aplikasi yang berjalan pada perangkat mobile seperti smartphone dan tablet. Aplikasi ini bisa digunakan untuk berbagai kebutuhan seperti komunikasi, edukasi, dan hiburan.

02. Platform Mobile

Platform adalah sistem tempat aplikasi dijalankan.

jenis platform:

• Android → Sistem operasi mobile paling banyak digunakan

• iOS → Sistem operasi pada perangkat Apple

Setiap platform memiliki aturan dan bahasa pemrograman masing-masing.

03.Bahasa Pemrograman Mobile

Bahasa pemrograman digunakan untuk membuat aplikasi mobile.

contoh:

• Java / Kotlin → Untuk Android

• Swift → Untuk iOS

• Dart → Untuk framework Flutter

Pemilihan bahasa tergantung pada platform yang digunakan.

04.Tools dan Framework

Tools dan framework membantu mempermudah proses pengembangan aplikasi.

contoh

• Android Studio → IDE untuk membuat aplikasi Android

• Flutter → Framework untuk membuat aplikasi multiplatform

• React Native → Framework berbasis JavaScript

Dengan tools ini, developer bisa membuat aplikasi lebih cepat dan efisien.

05. User Interface (UI) dan User Experience (UX)

UI adalah tampilan aplikasi, sedangkan UX adalah pengalaman pengguna saat menggunakan aplikasi.

Contoh:

• UI → tombol, warna, layout

• UX → kemudahan navigasi, kenyamanan penggunaan

06.Pengujian dan Distribusi Aplikasi

Setelah aplikasi dibuat, perlu dilakukan pengujian sebelum dipublikasikan.

Tahapan:

• Testing → memastikan aplikasi berjalan dengan baik

• Debugging → memperbaiki error

• Distribusi → mengunggah aplikasi ke Play Store atau App Store

Proses ini penting agar aplikasi siap digunakan oleh pengguna.
