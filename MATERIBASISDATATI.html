Teori Dasar

01. Apa itu basis data?

Basis data adalah kumpulan data yang disusun secara sistematis dan disimpan dalam komputer sehingga dapat diakses, dikelola, dan diperbarui dengan mudah. Contohnya seperti data siswa, data buku perpustakaan, atau data pelanggan.

02. Jenis-jenis Basis data

Relasional → Data disimpan dalam bentuk tabel (contoh: MySQL)

- Non-Relasional (NoSQL) → Data tidak berbentuk tabel (contoh: MongoDB)

- Terpusat → Data disimpan di satu tempat

- Terdistribusi → Data tersebar di beberapa lokasi

04. DBMS (Database Management System)

DBMS adalah perangkat lunak yang digunakan untuk mengelola basis data. Fungsi DBMS:

1. Menyimpan data

2. Mengatur data

3. Mengambil data dengan cepat

Contoh:

- MySQL

- PostgreSQL

- Oracle

Praktik

05. Sql

SQL adalah bahasa yang digunakan untuk mengakses dan mengelola data dalam basis data.

Contoh perintah:

• SELECT → Mengambil data

• INSERT → Menambahkan data

• UPDATE → Mengubah data

• DELETE → Menghapus data

06.Primary Key & Foreign Key

- Primary Key → Kunci utama yang membedakan setiap data (unik)

- Foreign Key → Kunci penghubung antar tabel

Contoh:

ID siswa sebagai primary key, lalu digunakan di tabel lain sebagai foreign key.
