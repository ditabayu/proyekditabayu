02. Jenis Data

Data adalah kumpulan fakta atau informasi yang akan dianalisis.

Jenis data:

• Data kualitatif → berbentuk kategori (contoh: jenis kelamin, warna)

• Data kuantitatif → berbentuk angka (contoh: umur, nilai)

Pemahaman jenis data penting untuk menentukan metode analisis yang tepat.

04. Ukuran Pemusatan Data

Ukuran pemusatan digunakan untuk mengetahui nilai tengah dari data.

jenis:

• Mean (rata-rata)

• Median (nilai tengah)

• Modus (nilai yang paling sering muncul)

Ukuran ini membantu memahami kecenderungan data

05. Ukuran Penyebaran Data

Ukuran penyebaran menunjukkan seberapa jauh data tersebar

Contoh:

• Range (jangkauan)

• Varians

• Standar deviasi

Semakin besar penyebaran, semakin beragam data tersebut

06.Analisis dan Interpretasi Data

Analisis data adalah proses mengolah data untuk mendapatkan informasi, sedangkan interpretasi adalah proses memahami hasil analisis.

Contoh:

• Menarik kesimpulan dari data

• Membuat keputusan berdasarkan hasil analisis

Tahap ini penting agar data dapat memberikan manfaat nyata.
