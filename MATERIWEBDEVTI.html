Introduction

01. Apa itu Web Development?

Web Development adalah proses membangun dan memelihara situs web. Ini mencakup segala hal mulai dari halaman teks statis sederhana hingga aplikasi web yang kompleks dan jejaring sosial.

Secara umum dibagi menjadi tiga bagian utama:

  • Frontend: Apa yang dilihat pengguna (UI/UX).
  • Backend: Logika di balik layar dan server.
  • Database: Tempat menyimpan data pengguna.

Lanjut ke pondasi utama web! ✨

Struktur

02. HTML: Tulang Punggung Web

HTML (HyperText Markup Language) adalah bahasa standar yang digunakan untuk membuat struktur halaman web. Bayangkan HTML sebagai kerangka manusia.

Elemen penting dalam HTML5:

  • <header> & <footer> untuk navigasi dan info bawah.
  • <main> untuk konten utama.
  • <div> & <section> sebagai pembungkus konten.

Struktur sudah siap, mari kita hias! ✨

Design

03. CSS: Mempercantik Tampilan

CSS (Cascading Style Sheets) digunakan untuk mengatur gaya visual halaman web, seperti warna, tata letak, dan font. Jika HTML adalah kerangka, maka CSS adalah kulit dan pakaiannya.

Konsep Utama CSS:

  • Selectors: Memilih elemen mana yang akan dihias.
  • Box Model: Padding, Margin, dan Border.
  • Flexbox & Grid: Teknik tata letak modern.

Waktunya memberikan "otak" pada web kita! ✨

Interactivity

04. JavaScript: Interaksi Dinamis

JavaScript adalah bahasa pemrograman yang membuat web menjadi hidup. Dengan JS, kita bisa membuat animasi, memproses formulir, dan mengubah konten secara real-time tanpa reload halaman.

Apa yang bisa dilakukan JS?

  • DOM Manipulation: Mengubah elemen HTML lewat kode.
  • Event Handling: Merespon klik atau ketikan pengguna.
  • API Fetch: Mengambil data dari server lain.

Web harus bisa dibuka di HP juga, kan? ✨

Layout

05. Responsive Web Design

Responsive Design memastikan situs web Anda terlihat bagus di semua perangkat (Desktop, Tablet, dan Smartphone). Kita menggunakan Media Queries untuk menyesuaikan tampilan berdasarkan ukuran layar.

Framework Populer:

  • Bootstrap: Menggunakan sistem grid 12 kolom.
  • Tailwind CSS: Menggunakan class utility-first.

Terakhir, mari simpan data kita! ✨

Server Side

06. Backend & Database

Backend adalah bagian server yang mengelola logika aplikasi dan berkomunikasi dengan database. Tanpa ini, kita tidak bisa melakukan login atau menyimpan data belanja.

Teknologi Populer:

  • Node.js: Menjalankan JavaScript di server.
  • PHP: Bahasa klasik yang masih sangat kuat (Laravel).
  • MySQL/PostgreSQL: Database untuk menyimpan data relasional.
